# Legacy

Archived files kept for reference. Nothing here is evaluated by the flake.

- `config/` — old terminal/bar/rice configs
- `local/bin/` — old helper scripts
- `nix/desktop/` — COSMIC, Plasma, Sway and XFCE modules
- `nix/hardware/`, `nix/host-specific/`, `nix/darwin-base.nix`, `nix/home/darwin.nix` — MacBook and nix-darwin hosts
- `nix/templates/` — old development shell templates
